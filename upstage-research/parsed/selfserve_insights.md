# Self-Serve SaaS Best Practices for Mid-Market Developer Tools

## Key Conversion Benchmarks
- Median free-to-paid conversion (all PLG models): ~9%
- Opt-out trials (credit card required upfront): 48.8% conversion — 5x higher
- Opt-in trials (no CC): low single digits
- **Implication:** Requiring CC on signup dramatically improves conversion quality even at the cost of volume

## Time to Value (TTV) is the Core Metric
- TTV = time from signup to first meaningful outcome ("aha moment")
- Demandbase cut TTV by 55% through onboarding redesign and saw major conversion uplift
- For developer tools: the aha moment is the **first successful API call with real data** (not sample data)
- Best practice: Onboarding tours under 5 steps; focus on path to first value, not comprehensive feature coverage

## What Makes Self-Serve Work for Developer Tools
1. **Frictionless first call** — API key in <60 seconds, working code snippet copy-pasteable, no sales required
2. **Low/no credit card barrier to start** — credit-based free tiers (like Nanonets $200, Reducto 15K credits) outperform time-limited trials for developers
3. **Real sandbox with real documents** — not toy examples; let them process an actual PDF from their use case
4. **Clear per-unit pricing on the page** — pricing opacity forces sales calls and kills mid-market self-serve (Docsumo failure mode)
5. **SDK parity** — if a Python SDK ships 6 months before the Node.js SDK, JS-first mid-market developers self-select out before they ever convert
6. **In-product upgrade prompts** — when a user hits the free tier limit, show the next-tier cost *in context* (not a generic pricing page)

## Mid-Market vs. Enterprise Buying Differences
- Mid-market (50-500 employees): **Developer IS the decision-maker** (or has dominant influence); no procurement team; credit card purchase up to ~$5K/year is common
- Enterprise (500+ employees): Procurement, security review, SOC 2/HIPAA requirements, negotiated MSA
- **Gap:** Most document AI tools are built for enterprise buying motion; mid-market buyer gets enterprise friction with no matching value

## PLG Maturation (2026 State)
- "Full-stack PLG" = product-led acquisition + sales-assisted expansion (not pure self-serve)
- Mid-market entry via self-serve → CS-assisted expansion when volume crosses a threshold (~$500-1000/month)
- Developer tools in 2026: self-serve for teams up to ~10 seats; sales touch for multi-team rollout
